# 短剧视频转绘 Agent · 交互原型

面向短剧出海的视频转绘 Agent 纯前端交互原型，覆盖从原片管理到合成成片的四步工作流。各环节中间结果统一以结果卡片呈现在左侧对话框中，点击卡片即可在右侧工作区查看：

1. **原片管理**：批量上传、拖拽排序、删除、预览播放；入口页默认预置 5 个示例视频，无需上传即可直接发送进入下一步；本地上传支持一次最多 10 个视频、可多次追加，全部上传成功后才可发送；上传入口固定保留在左侧，已选视频以叠加缩略卡排列在入口旁边，支持查看进度和移除；上传入口也可切换到「百度网盘上传」，粘贴文件夹链接即可，提取码选填（Demo 模拟拉取）。进入原片管理后先「确认原片，进行视频解析」，右侧实时标注每个视频的解析成功 / 失败 / 未解析状态，左侧展示预计等待时长与解析进度；解析失败的视频可单独点击「重新解析」（Demo 首次解析会模拟 1 个视频失败，便于演示该能力），解析完成后才出现「提取资产」引导。确认原片后自动锁定，仅保留预览查看和失败视频重试，不可再上传、删除或调整顺序
2. **资产确认**：角色主图 / 场景 / 道具资产提炼、转绘提示词、参考图、批量生成与前后对比；每张资产图支持从本地上传替换，或从项目资产中勾选复用；场景图、道具图和角色主图支持转绘前后对比，角色妆造图单独对比；资产表支持导出 Excel（项目信息、角色、场景、道具多工作表）
3. **分镜转绘**：分镜序列、转绘前 / 转绘后双画面对照、提示词位于视频下方、单个 / 批量转绘；每个分镜缩略图右上角支持单条视频下载与生成历史查看，可在多个生成版本间切换，切换后预览与成片同步更新
4. **合成成片**：展示合成后的最终视频，沿用并迁移原片 BGM；支持转绘前 / 转绘后对比查看，右上角可下载成片（Demo 使用浏览器端生成的演示视频，不支持录制时回退为预览图）

## 本地运行

项目无构建步骤、无第三方依赖，直接启动任意静态文件服务即可：

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。

也可以直接双击 `index.html` 运行。

## 目录结构

```text
.
├── index.html    # 页面入口
├── styles.css    # 视觉样式
├── data.js       # 演示数据、SVG 占位画面与状态
└── app.js        # 页面渲染与交互逻辑
```

## 说明

- 点击项目右上角「项目资产」可打开资产库，已生成的角色、场景、道具和视频分镜会自动归档，角色详情支持查看造型与音色。
- 画面均为 `data.js` 中 `drawScene()` 生成的 SVG 占位图，用于演示风格切换与转绘前后对比。
- 视频上传、生成、导出等能力为交互模拟，不会真实调用模型或产出视频文件。
- 目标地区、画风（仿真人 / 3D 动漫 / 2D 动漫）、画幅等选项会即时更新项目状态和演示画面。
