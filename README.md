# 短剧视频转绘 Agent · 交互原型

面向短剧出海的视频转绘 Agent 纯前端交互原型，覆盖从原片管理到合成成片的完整五步工作流：

1. **原片管理**：批量上传、拖拽排序、删除、预览播放
2. **剧本本土化**：按目标地区生成本土化剧本，人名、剧名、分集标题、场次标题同步本地化
3. **资产确认**：角色 / 场景 / 道具资产提炼、转绘提示词、参考图、批量生成与前后对比
4. **分镜转绘**：分镜序列、分镜提示词与视频对照、单个 / 批量转绘、原片与转绘效果对比
5. **合成成片**：分镜进度、成片预览、分辨率与导出格式选择

## 在线体验

GitHub Pages 部署完成后，可直接通过仓库的 Pages 地址访问。

## 本地运行

项目无构建步骤、无第三方依赖，直接启动任意静态文件服务即可：

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。

也可以直接双击 `index.html` 运行。

## 目录结构

```text
.
├── index.html    # 页面入口
├── styles.css    # 视觉样式
├── data.js       # 演示数据、SVG 占位画面与状态
└── app.js        # 页面渲染与交互逻辑
```

## 说明

- 画面均为 `data.js` 中 `drawScene()` 生成的 SVG 占位图，用于演示风格切换与转绘前后对比。
- 视频上传、生成、导出等能力为交互模拟，不会真实调用模型或产出视频文件。
- 目标地区、画风、画幅等选项会即时更新项目状态和演示画面。
